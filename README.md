## How it works

`main.py` (Python 3.13, standard library only) writes the single tagline
above to the output file — `/output/entry.txt` by default, or the path
given by `ENTRY_OUTPUT` / `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR` — with no
trailing newline and mode `0644`.

```sh
python3 main.py
```
